.schema books

Ця команда показує структуру таблиці books і підтверджує наявність NOT NULL, DEFAULT 1 та CHECK для поля copies_count.

CREATE TABLE IF NOT EXISTS "books" (
id INTEGER PRIMARY KEY,
title TEXT,
author TEXT,
publication_year INTEGER,
genre TEXT,
copies_count INTEGER NOT NULL DEFAULT 1 CHECK (copies_count >= 0)
);

Це результат виконання .schema books. Він підтверджує, що поле copies_count має обмеження NOT NULL, DEFAULT 1 і CHECK.

INSERT INTO books (id, title, author, publication_year, genre)
VALUES (8, 'Книга за замовчуванням', 'Тестовий автор', 2026, 'Тест');

Ця команда додає нову книгу без зазначення copies_count. Оскільки для цього поля встановлено DEFAULT 1, SQLite автоматично встановлює значення 1.

SELECT * FROM books WHERE id = 8;

Ця команда перевіряє створений запис із id 8.

8|Книга за замовчуванням|Тестовий автор|2026|Тест|1

Цей результат підтверджує, що SQLite автоматично встановив copies_count = 1.

UPDATE books
SET copies_count = -5
WHERE id = 8;

Ця команда намагається змінити кількість примірників книги на -5. Значення порушує умову CHECK.

Runtime error: CHECK constraint failed: copies_count >= 0 (19)

Ця помилка виникла тому, що CHECK забороняє встановлювати для copies_count від’ємні значення. Це показує, що CHECK працює не тільки під час INSERT, а й під час UPDATE.

SELECT * FROM books WHERE id = 8;

Ця команда повторно виводить книгу з id 8, щоб перевірити, чи змінилося значення після невдалого UPDATE.

8|Книга за замовчуванням|Тестовий автор|2026|Тест|1

Цей результат показує, що значення copies_count залишилося 1, оскільки некоректне оновлення було відхилено обмеженням CHECK.

NOT NULL — не дозволяє залишати обов’язкове поле порожнім, тому забезпечує наявність необхідних даних.

UNIQUE — не дозволяє дублювати значення в полі, тому кожен номер телефону читача має бути унікальним.

CHECK — перевіряє відповідність значення заданій умові, тому кількість примірників книги не може бути від’ємною.

DEFAULT — автоматично встановлює значення, якщо воно не було вказане під час додавання запису, тому для нової книги copies_count автоматично отримує значення 1.
