UPDATE ... SET col = col + 1 збільшує поточне значення стовпця на 1. UPDATE ... SET col = <number> встановлює конкретне значення незалежно від попереднього.
NOT NULL, UNIQUE і CHECK перевіряються під час UPDATE, тому що оновлений запис повинен відповідати обмеженням таблиці. Зовнішні ключі SQLite перевіряє лише тоді, коли увімкнено PRAGMA foreign_keys = ON.
Якщо було б встановлено ON DELETE CASCADE, то після видалення книги автоматично видалилися б усі пов'язані записи з loans.
DELETE без WHERE небезпечний тим, що видаляє всі записи таблиці. Помилка типу або порушення обмеження зазвичай просто зупиняє операцію, а DELETE без WHERE може успішно виконатися і втратити всі дані.
